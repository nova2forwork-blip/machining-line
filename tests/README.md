# ชุดทดสอบอัตโนมัติ (pytest) — Artclad Production ฝั่ง office

309 เทสต์ · ตรรกะคำนวณของหน้า Release 250 เทสต์ + กติกาในฐานข้อมูล 59 เทสต์
ทุกเทสต์มี **Test ID** (ในชื่อพารามิเตอร์ หรือบรรทัดแรกของคำอธิบายเทสต์) · **ข้อมูลทดสอบ** และ **ผลที่คาด** เขียนอยู่ในเทสต์นั้นเอง

## วิธีรัน

```bash
python -m venv .sim/pyenv
```
```bash
.sim/pyenv/Scripts/python -m pip install -r tests/requirements.txt
```
```bash
.sim/pyenv/Scripts/python -m pytest tests -v
```

- ต้องมี `node` (เรียกโค้ดจริงใน `src/release/releaseCore.js` · `orderSheet.js` ผ่าน `tests/js_bridge.mjs` — ไม่มีสำเนาตรรกะใน Python)
- เทสต์ฐานข้อมูลต้องเปิด Supabase ในเครื่อง (`supabase start`) และรัน migration ครบ · ถ้าไม่ได้เปิด = **SKIP** (ไม่ใช่ FAIL)
- รันเฉพาะกลุ่ม: `-m positive` · `-m negative` · `-m boundary` · `-m regression` · `-m db` · `-m "not db"`
